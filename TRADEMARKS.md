# The Kelpi name and logo

The code in this repository is released under the [MIT License](LICENSE). That license covers
the code. It does not cover the Kelpi name or the kelpie logo.

You are welcome to say that your project works with Kelpi, builds on it, or is a fork of it.
Please do not call a modified build "Kelpi", ship it with the Kelpi logo, or present it as the
official app. A fork should take its own name and logo.

The logo files in this repository (`docs/assets/`, `packages/core/assets/` and the site's
favicons) are here so the app, its docs and kelpi.sh can use them, not as permission to reuse
the mark elsewhere.

Questions about using the name or logo: open an issue.
