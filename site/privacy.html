Privacy

Kelpi has no accounts, so neither this site nor the app knows who you are. This page says what does leave your device, and where it goes.

This website

  • It sets no cookies and runs no analytics or tracking scripts.
  • Its fonts and images are served from kelpi.sh itself, not from a third party.
  • When the home page loads, your browser asks GitHub's public API for the latest release so the download button can point at it. GitHub receives that request under the GitHub Privacy Statement.
  • Downloads come from GitHub Releases.
  • The service that hosts this site may keep standard request logs, such as IP address and browser, to keep it running.

The Kelpi app

  • Your workspaces, layouts and settings stay on your Mac, in a database under Application Support and in ~/.config/kelpi/config.
  • Kelpi has no analytics and no crash reporting.
  • It checks GitHub for updates only when you choose Check for Updates or turn on automatic checks.
  • Pull request status for a workspace comes from your own GitHub command line tool, when it is installed and signed in.
  • The daemon listens on loopback only. Other devices reach it only if you set up remote access over your own tailnet, and every client needs its token.
  • Agents you run in Kelpi, such as Claude Code and Codex, talk to their own services under their own terms. Kelpi does not sit between them.
